# ☕ Brew & Bite Website

> **Premium Chilled Coffee & Bakery Bites**  
> Designed with modern Gen-Z aesthetics, responsive layout, interactive frame-by-frame scroll animation, and smooth floating glass navigation.

---

## ✨ Features

- **🎞️ Frame-by-Frame Scroll-Driven Animation:** 222 high-resolution product frames scrub smoothly as the user scrolls.
- **✨ Two-Column Hero Composition:** Left-aligned bold typography with pill tags and CTA paired with a right-aligned glass animation showcase.
- **🧭 Floating Glass Navigation Bar:** Transparent floating navbar that dynamically adapts with backdrop blur on scroll, with smooth anchor linking and mobile drawer menu.
- **🛍️ Menu & Product Showcases:** Signature Brews, Bakery Bites, "The Perfect Match" gallery, and brewing process.
- **📱 Fully Responsive:** Optimized for Mobile, Tablet, Laptop, and Desktop screens.
- **⚡ Vercel Ready:** Includes `vercel.json` and `package.json` for zero-configuration 1-click deployment.

---

## 🚀 Getting Started

### Local Preview

You can preview the site using any static web server:

#### Option 1: Python
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000/`.

#### Option 2: Node.js / NPX
```bash
npx serve .
```

---

## ☁️ Deploying to Vercel

1. Push this repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import the **`Brew-Bites-Website`** repository.
4. Keep the default settings (Framework Preset: **Other**) and click **"Deploy"**.
5. Your website is live in seconds!
